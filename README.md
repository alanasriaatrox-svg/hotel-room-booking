# \# Hotel Reservation Management System

# 

# \## 1. Project Description

# 

# Hotel Reservation Management System is a Python application designed to manage hotel room reservations.

# 

# The application allows users to check room availability, book rooms, cancel reservations, and calculate the total price of a stay.

# 

# \## 2. Core Features

# 

# \- \*\*Check Availability:\*\* Check whether a hotel room is available.

# \- \*\*Book a Room:\*\* Reserve an available room.

# \- \*\*Cancel a Booking:\*\* Cancel an existing reservation.

# \- \*\*Calculate Price:\*\* Calculate the total cost based on the room price and the number of nights.

# 

# \## 3. User Stories

# 

# \- As a user, I want to check room availability so that I can know which rooms are free.

# \- As a user, I want to book an available room so that I can reserve it.

# \- As a user, I want to cancel my reservation so that the room becomes available again.

# \- As a user, I want to calculate the price of my stay so that I know the total cost.

# 

# \## 4. Acceptance Criteria

# 

# | Feature | Acceptance Criteria |

# |---|---|

# | Check Availability | Returns True if the room is available and False otherwise. |

# | Book a Room | Successfully books an available room. |

# | Book a Room | Rejects a room that is already booked. |

# | Cancel Booking | Makes a reserved room available again. |

# | Cancel Booking | Rejects cancellation if no booking exists. |

# | Calculate Price | Returns the room price multiplied by the number of nights. |

# | Validation | Rejects nonexistent room numbers. |

# | Validation | Rejects zero or negative nights. |
